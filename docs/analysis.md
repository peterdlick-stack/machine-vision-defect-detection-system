# 1. 项目目标

针对微型电子元件引脚、精密注塑件浇口等微小区域，在光强、相机温度、反光率变化导致灰度漂移时，通过多谱采集、特征基因匹配、动态阈值和分层融合减少帧间对齐错误与伪缺陷。本项目实现可运行、可追溯的大学工程原型；不把合成数据实验当作微米级工业精度认证。

# 2. 需求来源

软件依据技术方案实现，以下区分方案要求、缺失信息和工程补充。原始技术文档、绘图及其提取副本不随仓库分发。

# 3. 功能需求

## 原文定义

- R1：可见光与近红外成对采集，每帧绑定 L/T/R 干扰包和16位标识符。
- R2：干扰 min-max 归一化，C=αL L+αT T+αR R，参数和为1。
- R3：二级小波融合；空间锚点、Canny轮廓链码、Sobel梯度、GLCM纹理熵形成四组128维归一化特征，与干扰包关联。
- R4：基准灰度±k1 C；梯度允许偏差=k C。
- R5：低、中、高干扰下动态权重，余弦相似度加权，结合动态阈值验证；基准选干扰较小且清晰的帧。
- R6：高置信且低漂移均值融合；高漂移先对齐、校正、按置信度融合；低相似区域过滤。
- R7：历史记录包括基因串、干扰包、匹配、融合评价；SGD更新耦合系数、匹配权重、判定阈值。

## 用户明确要求的工程能力（非原专利要求）

单图/文件夹、USB/视频、工业相机适配接口、演示样本、模型可替换、参数编辑、双图界面、结果列表、异步推理、停止、历史、CSV导出、错误提示、日志、自动保存、测试。增加“同一目标序列”显式开关，避免将不同零件图片强行跨帧匹配。原文没有语义类别字典，界面仅显示“候选异常 / 跨帧匹配异常”，不伪造划痕、裂纹等已训练分类能力。

# 4. 非功能需求

原文实施例：30fps采集、500–900nm双波段、10–100μs曝光（例20μs）、0–10000lux、温度精度±0.1℃、工业以太网、权重毫秒级调整。这些是硬件与生产系统目标，桌面Demo不承诺达标。原文没有可验收的准确率、召回率数值。拟合误差≤0.02、学习收敛差≤0.01属于需要实测样本的标定目标。软件要求：GUI主线程不推理；任务可停止；坏图继续批处理；错误日志可追踪；唯一输出文件名；源图不覆盖；相对配置路径相对项目；明确合成/NIR缺失/未确认状态。数据库每次操作独立连接，后台线程可用。

# 5. 系统架构

原图：采集→特征提取→动态权重匹配→融合→输出；采集→耦合→阈值→匹配；耦合→学习→匹配，学习→耦合。正文补充每次检测数据进入学习历史。没有指定编程语言、GUI框架或学习深度网络。

实现采用 Python≥3.10、NumPy、OpenCV、PyWavelets、PySide6、SQLite、JSON、logging。无需PyTorch/YOLO即可运行；统一BaseDetector接口支持替换，额外YOLO适配仅在显式选择且存在本地权重时加载。核心默认是文档算法原型，不用通用YOLO替代专利流程。

# 6. 数据流

FramePacket(可见光、可选NIR、时间、会话UUID+16位ID、L/T/R来源) → 校验尺寸/同步 → min-max干扰分析 + 二级小波融合/单谱降噪 → 补充候选区域提议 → 四组特征基因 → 基准选择 → 动态权重余弦匹配 + 灰度/梯度阈值验证 → 均值或校正融合/过滤/保留未确认候选 → 结果对象 → GUI → PNG/JSON/SQLite → 可选人工标定反馈 → SGD参数状态。

独立图片每次清空基准；序列按名称排序共享基准；改变分辨率清空基准；单帧不能证明跨帧一致，必须标“未确认”。正常空白图输出零候选。16位标识会回绕，因此附会话UUID避免历史冲突。

# 7. 算法需求

## A 文档明确要求

- 二级小波分解，低频加权平均、高频绝对值最大、逆变换；Canny、链码、Sobel、GLCM d=1 θ=0；四组128维归一化向量。
- 归一化区间：L [0,10000]、T [20,60]、R [0.1,0.9]。α范围分别[.2,.4]、[.3,.5]、[.2,.4]，和为1；示例(.3,.4,.3)。原文例(.6,.3,.5)得C=.45。
- 干扰<.3低，≥.7高；低权重(.2,.2,.5,.1)，高(.3,.4,.1,.2)。中等原文未定义。
- k1∈[5,15]，k示例3；融合阈值.75，漂移比例10%，伪缺陷相似阈值.5；100帧无干扰基准灰度；初始100组最小二乘标定。
- SGD lr=.001，每新增1000组一次，差≤.01收敛；更新系数、权重和阈值。

## B 提及但缺细节

工业相机/传感器协议、物理反光率反演、跨光谱几何标定、候选提取、特征如何编码为128维、学习标签与损失、参考清晰度评分、多帧缓存生命周期。文档未指定小波基、低频比例或检测类别。

## C 为可运行而补充（不得混称原文算法）

默认haar、低频各.5；单谱高斯降噪；局部背景残差阈值+连通轮廓候选；空间四角插值/链码方向直方图/Sobel直方图/熵分布嵌入128维；中等干扰线性插值；空间距离门限与一对一贪心匹配；ROI缩放对齐仅适合小幅平移/尺度变化；基准清晰度用Laplacian方差。R缺失用明确标注的配置模拟值，绝不把普通灰度图当真实NIR。参数默认值是演示初始化，未经实测标定。

在线学习默认关闭；提供真实可运行的标定/人工反馈更新工具，只有显式输入 measured_c / match_label 才学习，避免拿自身预测当真实标签。新基准/未匹配区域保留为“未确认”，不把首次出现的真实缺陷删除。保存过滤原因和融合前后清晰度（代理指标，并非准确率）。

# 8. 缺失信息与冲突

无真实工业图像/缺陷标注/模型/相机SDK/同步协议/光学标定/100帧基准/100组标定数据。无物理分辨率，因此不能声称微米级测量。提供固定种子合成图像、成对合成NIR、干扰JSON和视频，明确标为演示。

冲突1：大纲的微光反射与六模块，采用正式文档可见光/NIR七模块。冲突2：draw.io匹配失败直接过滤，正文给出.75融合阈值与.5伪缺陷阈值两个值；按正文分三态：≥.75且阈值通过可融合，<.5过滤，中间/阈值失败保留未确认。冲突3：正文“高于”，图中“≥”，边界统一≥并在测试固定。冲突4：正文最小二乘“100组”与“三维每5%测试点全组合”数量不一致；标定要求至少100组有效样本，不臆造完整网格。冲突5：正文四顶点不适于任意轮廓，工程上采用外接框四角；128维编码由软件补全。近红外缺失时单谱流程仍可演示，界面与结果记录来源。
