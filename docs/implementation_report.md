# 实现报告

本项目已从三份原始资料恢复需求，完成可运行的Python桌面工程、真实GUI运行验证和自动测试。默认无需模型。原始技术资料未包含在本发布包中。当前成果是文档算法的可执行原型，尚不能作为工业精度已验证系统交付。

## 1. 报告范围

本报告保留此前 macOS 环境下的实现与验证记录；整理发布包时未重新执行运行测试。原始技术文档、绘图文件及提取副本不随仓库分发。

## 2. 核心需求与实现对照

| 原文/用户需求 | 实现 | 当前边界 |
|---|---|---|
| 可见光/NIR和干扰同步绑定 | FramePacket、唯一session+16位帧号、图像对和旁车JSON | 文件配对/模拟传感器可运行；硬件同步需SDK |
| L/T/R min-max和耦合效应 | 范围校验、归一化、三系数加权，原文.45算例测试 | 默认(.3,.4,.3)仅示例值 |
| 二级小波多谱预处理 | PyWavelets；低频均值、高频绝对值最大 | 小波基haar为补充；真实图像需先几何配准 |
| 四类缺陷基因 | 四角锚点、Canny链码、Sobel分布、GLCM熵；各128维 | 具体编码规则与候选提议为补充 |
| 动态阈值 | Gbase±k1*C、梯度允许k*C | 无100帧标定时使用明确标识的单参考帧Demo均值 |
| 基准灰度来自100帧 | `scripts/build_baseline.py`流式均值、NPZ加载 | 有真实100帧后可用，程序无法证明采集无干扰 |
| 动态权重与相似度 | 原文低/高权重；中间线性插值；加权余弦 | 空间门限、一对一贪心匹配为补充 |
| 分层融合与过滤 | 均值融合、局部缩放对齐/灰度校正/置信度加权、过滤审计 | 非刚性运动/旋转/复杂跨谱配准尚不支持 |
| 参考帧选举 | 较低干扰且清晰度未显著下降时更换参考 | Laplacian清晰度与80%容差为补充 |
| 历史数据库 | SQLite及完整JSON，基因/干扰/匹配/融合指标全保存 | 没有生产级数据生命周期管理 |
| 初始干扰参数拟合 | 至少100组、有界约束最小二乘、误差报告 | 真实标定数据缺失；仅用合成数据测试数学实现 |
| SGD优化耦合、权重和阈值 | lr=.001、每1000新ID遍历一次、人工标签驱动、原子状态保存 | 不在无标签检测时自动“自学习”；损失/更新规则为补充 |
| 单图、批量、摄像头、视频 | GUI选择与异步执行、停止、异常恢复 | USB实机/工业相机未测试；视频已测 |
| 可视化、保存、历史与CSV | 双图、结果表、状态/耗时、图像/JSON/SQLite、历史预览、CSV | 没有假设未知缺陷类别；不输出未经训练的裂纹/划痕分类 |
| 可替换模型 | Protocol接口、Demo与可选本地YOLO | 没有真实权重，YOLO只验证缺失路径错误 |

## 3. 冲突处理

大纲的六组件“微光传感/双特征锚点”没有覆盖正式文档七模块；按正式文档实现VIS/NIR与四类基因。draw.io对匹配失败直接过滤，而正文给出.75融合与.5过滤双阈值；采用正文三态流程。图中≥与正文“高于”统一为≥。新的空间候选保留为待复核，避免把首次出现的缺陷直接删掉。细节与全部参数见 `analysis.md`。

## 4. 最终技术架构

Python3.10+；历史验证环境使用Python3.12.14。OpenCV/NumPy/PyWavelets负责算法；PySide6（Essentials分发）负责GUI；SQLite与JSON负责存储；logging记录运行与错误。没有引入网络服务或深度学习依赖作为默认启动条件。

- `app/main_window.py`：桌面工作台、参数、历史、结果呈现；`app/worker.py`：QThread与停止事件、显示背压。
- `vision/`：数据契约、预处理、候选/特征、阈值/融合、视频与工业协议接口、100帧标定。
- `models/`：无模型文档原型与可选YOLO。
- `services/`：输入/推理/保存编排、SQLite与CSV、受监督标定和学习。
- `scripts/`：固定种子演示生成与两类标定入口。
- `utils/config.py`：参数校验、统一项目根目录相对路径。

所有推理和采集在后台线程，GUI只显示；逐帧确认显示避免消息队列无限积压。任务结束/关闭释放采集；坏图单独记录继续批处理。SQLite连接不跨线程共享，每次事务后关闭。UUID结果路径、防覆盖检查、失败清理、Unicode图像IO和CSV公式转义已实现。

## 6. 实际验证

历史验证时间：2026-09-27，macOS arm64。原报告记录如下：

1. 依赖安装到项目 `.venv`，未使用系统Python3.9运行本项目。
2. `ruff check`：项目源码全部通过；`compileall`：全部通过。初次lint范围误包含第三方环境，随后明确限定项目源码目录，未修改依赖包。
3. `python main.py --demo`：6帧完整执行，每帧2个候选，前两次有效后续低漂移匹配各2个；高漂移超阈值保留复核。
4. 原生GUI烟雾验证：真实macOS窗口、真实QThread、6帧、零错误；双图/结果表可显示。首次受限沙箱无屏幕，切换桌面权限后成功，非仅offscreen模拟。
5. `pytest`：**19 passed**。覆盖配置、公式、预处理、特征、Demo与重复帧匹配、空白图、参考重置、两条融合分支、持久化/CSV、中文路径、坏图、完整序列、缺失模型、监督学习/去重、16位回绕、100帧标定、历史防覆盖、非法旁车、GUI坏图继续、视频停止、图片选择与导出调用链。

证据：`test_results.xml`、`verification.json`、`../assets/gui_preview.png`。运行 CSV 和数据库未包含在本发布包中。截图由实际Qt窗口生成并人工查看。

## 7. 如何运行

```bash
source .venv/bin/activate
python main.py
```

点击“演示序列”后“开始检测”。命令行演示 `python main.py --demo`；测试 `QT_QPA_PLATFORM=offscreen python -m pytest -q`。完整新环境安装、配置、输入与FAQ见根目录README。

## 8. 如何接入真实模型与硬件

YOLO：安装可选依赖，提供本地可信权重，配置model_path并选择YOLO。不会隐式下载不存在的best.pt。其他算法实现BaseDetector协议并注册工厂；新模型需返回统一DetectionResult。

工业相机：实现IndustrialCamera协议，按SDK输出有真实同步时间/标识、VIS/NIR和实测干扰的FramePacket。真实反光率反演和跨谱配准需标定；软件并未把可见光灰度伪装成物理近红外或反光率。

## 9. 尚未完成工业验证的部分

没有真实光学硬件、传感器SDK、数据集、缺陷类别、训练模型或标注。工业以太网硬同步、20μs曝光、±.1℃传感精度、500–900nm、微米/亚微米检测属于硬件与生产目标，不可能由本次纯软件Demo证明。候选提议、特征编码、ROI配准和监督学习损失属于明确记录的工程补全，而非声称已还原未公开算法。

最值得继续的工作是采集同目标VIS/NIR和同步干扰的标注数据，完成100帧灰度基准、100组干扰标定，并建立独立测试集。随后比较固定阈值与动态流程的漏检/误检、匹配精度和吞吐；再替换工业SDK及配准模块。
